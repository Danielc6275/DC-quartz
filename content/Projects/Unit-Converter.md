# Unit Converter

A unit conversion application designed to make converting measurements simple and convenient.

## 📖 Overview

The Unit Converter is a project I developed to practice programming and build a useful application.

The goal was to create a program that converts between metric and imperial units.

## ✨ Features

Unit Conversion:** Convert values between supported measurement units.
- **Simple Interface:** Easily enter values and select units.
- **Conversion Results:** Display calculated results in a readable format.

- JavaScript
- HTML
- CSS
